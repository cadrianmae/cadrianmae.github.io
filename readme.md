# cadrianmae.github.io

Personal website built with Hugo and TailwindCSS, based on [Hugoplate](https://github.com/zeon-studio/hugoplate)

## Features

- **Hugo**: A fast and flexible static site generator.
- **TailwindCSS**: A utility-first CSS framework for rapid UI development.
- **JavaScript**: Enhancements and functionality for your site.
- **HTML**: The structure of your web pages.
- **CSS/SCSS**: Custom styles for your project.
